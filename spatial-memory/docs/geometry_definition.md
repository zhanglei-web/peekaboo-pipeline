# 检查充分性 Q 的几何计算与累积更新

本文按论文方法定义描述检查充分性的计算。假设每次检查均可建立非空的几何参考范围，并获得计算所需的深度、相机标定及帧间配准结果。在该假设下，每次检查均产生位于 [0,1] 的连续几何评分。

## 1. 定义与基本假设

检查充分性描述一个指定搜索范围在检查过程中获得的几何观测覆盖程度。我们区分单次检查评分与累积检查状态：

- 单次评分 q_t(u)：第 t 次事件对搜索单元 u 获得的几何覆盖比例。
- 累积状态 Q_t(u)：截至第 t 次事件，同一搜索单元获得的历史最高检查评分。
- 物体状态 Q_t(o)：物体 o 已发现搜索单元的平均充分性。
- 大区状态 Q_t(m)：大区 m 已发现物体分组的平均充分性。

搜索单元对应明确的空间范围。同一物体的外部占地区域和内部空间分别定义为不同单元，各自建立参考范围并维护检查状态。下文以操作物体初始位置对应的局部外部支撑范围为例，说明具体几何计算。

该定义采用两个基本假设：第一，每次检查的参考范围在该事件内固定；第二，同一单元在累积期间具有一致的空间语义和被搜索内容。相机运动、视角变化及遮挡物移开可以改变可见部分，但不改变该单元所指代的搜索范围。

## 2. 单次检查的几何评分

### 2.1 建立固定参考范围

对于事件 t 中的搜索单元 u，选取操作物体初始位置附近的局部支撑面。利用双目深度恢复操作物体及其邻域的三维点，并拟合局部支撑平面：

\[
\Pi_t(u)=\{\mathbf{x}\mid\mathbf{n}^{\top}\mathbf{x}+d=0\},
\qquad \|\mathbf{n}\|_2=1.
\]

将操作物体的三维点投影到支撑面：

\[
\operatorname{proj}_{\Pi_t(u)}(\mathbf{x})
=\mathbf{x}-(\mathbf{n}^{\top}\mathbf{x}+d)\mathbf{n}.
\]

根据投影得到的局部占地范围进行采样，构成非空参考点集合：

\[
\mathcal{R}_t(u)=\{\mathbf{p}_1,\ldots,\mathbf{p}_{N_t(u)}\},
\qquad N_t(u)>0.
\]

参考范围在统计覆盖率之前确定，并在本次事件内保持不变。因此，物体被移开或局部区域重新遮挡时，评分分母保持一致。所得分数针对该参考范围，不自动扩展到同名物体的内部或整个文字候选区域。

### 2.2 三帧配准与可见性判断

每次事件采用由 Qwen3.8-8B 从带时间戳和动作信息的实际候选图像中共同选择的 Pre、PNR、Post 三帧，记为 k ∈ {Pre, PNR, Post}。事件和接触簇起止图像是重要参考，但不预先占据任何角色。使用静态背景对应与 RGB-D 位姿估计，将参考点变换到各帧相机坐标系。

对于参考点 p，其在第 k 帧的相机坐标和像素位置分别为：

\[
\mathbf{p}^{(k)}=\mathbf{T}_{t,k}\mathbf{p},
\qquad
\mathbf{x}^{(k)}=\pi(\mathbf{K}\mathbf{p}^{(k)}),
\]

其中 T 作用于齐次坐标，K 为相机内参，π 表示透视投影。令 z^(k) 为变换后参考点的深度，D_(t,k) 为观测深度图，F_(t,k) 为前景遮挡掩码。参考点通过可见性判定需要同时满足：

1. 位于相机前方且投影落在图像范围内；
2. 对应像素具有有效深度；
3. 观测深度与参考点预测深度之差不超过容差 ε；
4. 对应像素未被前景遮挡掩码否决。

记满足这些条件的参考点集合为 V_(t,k)(u)。其中深度一致性条件为：

\[
\left|D_{t,k}(\mathbf{x}^{(k)})-z^{(k)}\right|\leq\varepsilon.
\]

几何判定采用 ε = 0.02 m。未通过深度或遮挡检查的点不计入该帧的可见集合。

### 2.3 合并三帧证据

本次检查的有效可见集合取三帧并集：

\[
\mathcal{V}_t(u)=
\mathcal{V}_{t,Pre}(u)\cup
\mathcal{V}_{t,PNR}(u)\cup
\mathcal{V}_{t,Post}(u).
\]

单次检查充分性定义为：

\[
\boxed{
q_t(u)=
\frac{|\mathcal{R}_t(u)\cap\mathcal{V}_t(u)|}
{|\mathcal{R}_t(u)|}
}
\qquad q_t(u)\in[0,1].
\]

等价地，对每个参考点判断其是否至少在一帧被有效观测：

\[
q_t(u)=\frac{1}{N_t(u)}
\sum_{i=1}^{N_t(u)}
\max_{k\in\{Pre,PNR,Post\}}
\mathbb{1}[\mathbf{p}_i\in\mathcal{V}_{t,k}(u)].
\]

q_t(u)=0 表示没有参考点通过本次三帧的可见性判定；q_t(u)=1 表示全部参考点至少被有效观测一次；中间数值直接表示参考点覆盖比例。中间帧已经露出、结束帧重新被遮挡的点仍计入本次检查成果。

## 3. 累积更新机制

### 3.1 搜索单元层

新发现的搜索单元初始化为：

\[
Q_{\mathrm{init}}(u)=0.
\]

设 I_t 为事件 t 实际检查的单元集合。每次事件后按下式更新：

\[
\boxed{
Q_t(u)=
\begin{cases}
\max\{Q_{t-1}(u),q_t(u)\},&u\in I_t,\\
Q_{t-1}(u),&u\notin I_t.
\end{cases}
}
\]

对于本次刚发现的单元，以上更新使用初始化值作为先前状态。该算子保留同一范围的历史最佳几何评分；更低的新评分不会覆盖已有的较高评分。

例如，某单元先后得到 0.4、0.7 和 0.3，则累积状态依次为 0.4、0.7 和 0.7。最新单次评分与累积状态分别保存，便于区分当前检查结果和历史成果。

### 3.2 物体层与大区层

设 U_t(o) 为物体 o 截至事件 t 已发现的搜索单元集合。对于至少存在一个已发现单元的物体，定义：

\[
Q_t(o)=\frac{1}{|\mathcal{U}_t(o)|}
\sum_{u\in\mathcal{U}_t(o)}Q_t(u).
\]

设 O_t(m) 为大区 m 中至少具有一个已发现单元的物体分组集合。对于该集合非空的大区，定义：

\[
Q_t(m)=\frac{1}{|\mathcal{O}_t(m)|}
\sum_{o\in\mathcal{O}_t(m)}Q_t(o).
\]

物体层和大区层均采用等权平均。同一物体即使包含多个搜索单元，在大区层仍作为一个物体分组计权。尚未发现的范围不进入当前汇总分母；所有参与汇总的单元均具有数值状态。

### 3.3 新范围发现后的更新

发现新的待搜部分时，将其作为独立搜索单元加入对应物体，并初始化为 0。已有单元保留其累积成果，新单元不继承父区域或相邻单元的评分。

例如，同一物体原有单元 A 的状态为 0.6；发现新单元 B 后，B 初始化为 0，该物体的充分性变为 (0.6+0)/2=0.3。之后 B 获得 0.4 的检查评分，物体充分性变为 (0.6+0.4)/2=0.5。

因此，同一单元的状态随检查单调不减，而物体或大区的状态可以因已知搜索范围扩大而下降。

## 4. 重复证据与不确定证据

### 4.1 重复观测

同一事件内，通过参考点并集消除三帧间重复观测：同一点无论出现几次，只贡献一次覆盖计数。

不同事件之间，使用最大值算子避免重复评分被直接相加。该算子对相同证据的数值更新具有幂等性：

\[
\max\{\max\{Q,q\},q\}=\max\{Q,q\}.
\]

跨事件累积表示历史最佳单次覆盖水平，并不将不同事件的可见点解释为已经建立对应的空间并集。因此，不使用评分求和或独立概率乘积计算累积充分性。

### 4.2 局部几何不确定性

在参考范围已建立的前提下，局部深度不可靠、几何不一致或遮挡关系不明确的点不计入可见分子，同时保留在固定分母中。该处理仅累计通过可见性检查的几何证据。

局部点的不确定性不妨碍事件输出连续分数：分数仍由通过检查的点数除以固定参考点总数得到。另行保存逐点状态和质量诊断，供结果复算与检查。这里不额外引入未经校准的置信度乘权。

## 5. 场景变化与历史证据的有效范围

充分性以稳定搜索单元为索引，并记录其空间范围。相机视角改变、遮挡物移动或已观察范围重新被遮挡时，只要该范围及其被搜索内容保持一致，既有检查成果继续保留。

发现新的独立范围时，通过新增单元扩展记忆，而非将原有单元的分数传播给新范围。暂时检测到的新轨迹需要先关联到稳定单元，避免把同一对象的重复检测作为多个汇总项。

上述累积定义以单元范围和内容一致为条件。对于改变单元边界、内容或身份的变化，需要重新确定搜索单元及其累积区间；原区间的历史评分不能直接解释为新状态下的覆盖率。本节规定的是充分性的适用条件，不额外假设系统已实现自动变化检测或证据衰减。

## 6. 计算规则与复核

几何评分由参考范围、相机配准、深度一致性和遮挡检查直接计算，不通过语言提示词赋予数值。语义描述或对象关联结果可用于确定参考对象，但充分性数值由上述几何公式产生。

为保证计算可追溯，记录每次事件的参考区域、参考点、三帧位姿、逐点可见状态、评分及质量诊断。复核包括：

1. 确认事件、帧、相机标定和搜索单元对应一致；
2. 检查参考范围在事件内保持固定；
3. 检查静态背景配准和跨帧深度一致性；
4. 根据保存的逐点状态重新计算三帧可见并集与单次评分；
5. 按事件顺序重放最大值更新，并核对物体与大区均值。

几何计算可采用 Fast-FoundationStereo 估计深度，双目推理分辨率为 1280×960，评分坐标分辨率为 640×480，迭代次数为 4，左右一致性容差为评分坐标下 1.5 像素，默认可见性深度容差为 2 cm。

## 7. 论文正文精简表述

> 我们将检查充分性定义为指定局部搜索范围的几何观测覆盖程度。对于每次检查，首先将操作物体初始位置的三维点投影至局部支撑面，建立固定参考点集合。随后，将参考点配准到开始、中间和结束三帧，并依据深度一致性及前景遮挡判断其可见性。单次充分性为三帧可见参考点并集占固定参考点总数的比例，取值范围为 [0,1]。同一参考点在事件内仅计数一次；未通过几何可见性检查的点保留在分母中，不贡献覆盖计数。跨事件采用历史最大值更新单元充分性，并分别对已发现单元和物体分组进行等权汇总，获得物体及大区状态。新发现的待搜单元初始化为 0，已有单元保留历史成果。该定义假设每次检查的参考范围可建立、几何计算可完成，且同一单元在累计期间的空间语义及被搜索内容保持一致。累积状态表示历史最佳几何检查水平。
