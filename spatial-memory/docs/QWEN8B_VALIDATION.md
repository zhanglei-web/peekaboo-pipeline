## 计算依据与复算

1. 按最终源帧号与采集时钟同步左右目，使用 Double-Sphere 双目标定校正。
2. Fast-FoundationStereo 以 1280×960 推理，4 次迭代；左右互检后在 640×480 评分栅格保存深度，左右一致性容差为评分坐标下 1.5 像素。
3. 8B 在实际三帧校正图中定位操作物体；FastSAM-x 生成实例掩码。手部排除使用已有 100DOH 源帧检测，通过同一标定映射至评分栅格。
4. 仅根据初态的对象三维点和邻近表面选择支撑平面。相机—IMU 标定及此前 100 ms 内稳定的加速度方向用于排除墙面等不符合局部水平承托语义的平面；平面还须与初始物体接近。选择不读取后续覆盖率。
5. 将初始物体点投影至选定承托面，冻结占地参考。通过静态 RGB-D 配准和跨帧深度检查后，以 2 cm 容差及前景否决判断三帧的逐点可见性，求并集得到 q。
6. 从保存的 `visible` 数组重新执行 `any(axis=0).mean()`，结果与 q、记忆单元 Q 三者完全一致：`0.10044893378226712`。

局部深度未知点留在分母中；未知比例作为诊断，未额外删除该事件或缩小分母。参考范围或配准无法可靠建立时整项保持不可计算，遵循 3.md 对计算前提的要求。

## 单元身份、分组与歧义

S07 的同一物理占地被模型关联到不同文字父区域。几何编译按同一相机坐标中的占地重合进行事件内去重，只保存一个单元和一次覆盖值。该单元归入事件发现的操作物体分组；两个原始文字候选的 Q 仍为 null。关联歧义以 `ambiguous_parent_region_links` 保留，后续策略若要使用这些文字区域的 Q，须先解决该关联。

跨事件复用参考时，必须在同一录制内通过静态配准、平面距离及占地重合检查，再读取已有固定参考。单元范围或内容改变需新的累积区间；当前没有自动内容变化检测。容器内部的专门参考几何也尚未实现。

本轮每段仅运行一个事件；跨事件 max 已有单元测试，真实重复事件的几何参考复用尚未单独验证。实际几何运行环境及 Fast-FoundationStereo 源码版本写入机读摘要。

## 修复与验证边界

- 第一阶段坐标修订改用具名 `x_min/y_min/x_max/y_max`，由模型重新输出，再按固定字段序列化；程序不交换或补造无效坐标。S09 在此路径生成了有效目录。
- 多图请求使用独立 8B 服务：两个 32768 token 槽，每张图 1024 图像 tokens；候选帧全部保留。
- 手部排除改用真实源帧手部检测，避免模型给出的宽泛手部框删掉大部分物体。
- 支撑面加入实测 IMU 方向与接近物体的条件，避免仅按像素支持数把墙面选为下方承托面。
- 17 项单元测试通过，覆盖具名坐标、源帧引用、分辨率／深度单位换算、静态深度冲突、IMU 时间与方向、固定分母、局部范围独立记忆和 max 重放。

这些结果属于真实输入的功能及几何一致性验证，尚无独立人工复核的选帧、区域关联或覆盖真值准确率，`0.10045` 也不是准确率。完整原图、深度、模型响应、参考点和日志保留在本地 runs 目录，源码发布不包含原始视频或模型权重。
