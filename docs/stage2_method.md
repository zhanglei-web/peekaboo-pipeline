# 标注系统第二部分：从视频得到 Pre、PNR、Post 三帧、几何充分性与累积记忆

本文描述指定的完整处理链：**连续视频 → 自动事件区间 → 带时间戳与动作信息的重要候选帧 → Qwen3-VL-8B-Instruct 选择 Pre、PNR、Post → 逐搜索单元几何充分性 → 累积记忆**。与 [几何定义](geometry_definition.md) 配套，后者给出几何评分和累积公式，本文说明这些量从哪一次事件、哪三帧和哪一个搜索单元产生。

三帧的角色为：**Pre** 展示关键操作前的对象与待查空间状态；**PNR** 展示目标动作展开、空间暴露或状态变化最充分且画面清晰的时刻；**Post** 展示这次操作产生的结果或结束后的稳定状态。三帧都由 Qwen3-VL-8B-Instruct 从实际提供的候选图像中选择。事件起止帧与接触簇起止帧是重要参考图像，其角色由模型结合图像和动作信息判断，不预先指定。

## 1. 系统的两个部分

1. **搜索空间与身份**：建立候选区域目录，确定稳定的搜索单元、物体分组和大区，以及各自的空间边界和版本。候选检测框只用于定位和身份关联，不直接充当几何评分分母。
2. **事件证据与状态**：从视频识别本次检查，选择 Pre、PNR、Post，确认实际检查的单元，计算逐单元的几何评分 `q_t(u)`，更新累积状态 `Q_t(u)`，并将新记忆交给下一次决策。

一次事件可以包含拿起、移开、查看、放回等多个阶段，也可能涉及多个搜索单元。事件的连续区间、被选中的接触簇区间、三帧的时间跨度分别保存；三帧不替代事件边界。

## 2. 输入与时间对齐

每段录制登记 `episode_id`、目标描述、左目连续视频、源帧号和采集时间。完整几何计算还需对应的右目帧、双目标定、深度有效掩码及相机位姿。三帧中的 `source_frame_id` 始终指向原视频；事件裁剪后的局部序号不能作为跨模块身份。输入视频、帧索引、检测结果和模型配置保存哈希或版本，以便之后复算。

动作和图像按各自源时间对齐。离线动作识别窗口若用到某个时刻之后的图像，必须等这些图像到达后才可输出该结果。每条事件同时记录图像采集时间、事件结束时间、三帧选择完成时间、几何结果完成时间和记忆提交时间；后续决策只能读取当时已经提交的事件结果。

## 3. 当前方法如何从全视频得到事件

当前自动事件链按以下顺序运行：

```text
连续左目视频和源帧时间
  → 100DOH 手、物与接触检测
  → 接触区域上下文图像的 TSM 动作概率
  → 动作阶段＋手与物的轨迹、接触、外观变化证据
  → cycles 规则解码，得到按时间排序的事件区间
```

TSM 提供动作概率和阶段线索；它不直接决定事件起止。事件解码还检查接触是否持续、手是否真正松开、是否重新接近、对象外观或位置是否变化，以及是否出现可解释的操作收尾。“拿起后查看再放回”可以是一件完整事件；动作标签切换或短时漏检本身不构成新事件。由检测失败造成的空白不能当作已观察到的松手。输出每个事件的源帧起止、边界依据、质量标记和录制末尾是否截断。事件数量由预测区间产生，不把人工参考的事件个数或边界作为预测输入。

如果机器人提供同一时钟下的局部搜索动作 ID 和完成信号，信号可以限定本次事件的外层窗口；最终仍需根据实际图像和执行反馈定位有效操作，并保留信号来源。当前全视频自动实验使用上面的 TSM、接触和视觉证据链。

## 4. 如何在一次事件中选出 Pre、PNR、Post

### 4.1 确定被操作对象和有效接触簇

对每个已预测事件连同明确登记的前后文单独读取检测缓存，保留原视频源帧号；前后文只服务于本事件的状态比较，不改变事件边界。用 YOLO-World 识别接触物体的类别，结合 100DOH 接触框做实例关联和跟踪。类别不能确认时保留 `unknown`；不能把覆盖较大范围的柜体框自动当作被操作的小物体。

程序检查每段接触的对象连续性、有效接触帧数、手与物体的几何关系及框范围质量。短暂缺失仅在前后实例、外观、手部连续性和中间接触证据共同支持时连接；连接的空白帧不补算为实际接触。多个候选簇按有效接触数量和质量权重选择，范围歧义、短簇及截断保留标记。

事件起止帧、所选接触簇的首尾帧、首次明确接近或接触、移开或打开后的显露阶段、观察停顿以及动作收尾附近的清晰帧，均作为重要候选。接触簇首尾说明操作跨度，但**不是预先确定的 Pre 或 Post**。候选窗口需要保留足够的前后上下文；如果缺少能说明操作前或结果状态的图像，应记录上下文不足。

### 4.2 生成带时间戳和动作信息的候选图像

以事件早期的清晰图像作变化计算参考，先对静态背景做相机运动配准，再比较初始物体框、已观测运动走廊以及向外衰减的邻域内的局部 CLIP 特征变化。对可计算帧记录变化分数、配准有效性和图像质量。变化峰值只用于**提出值得查看的候选**，不直接表示区域的几何覆盖率，也不自动指定任何最终角色。

送给 Qwen3-VL-8B-Instruct 的候选图像按源帧号与时间戳排序并去重，覆盖事件前态、操作过程和结果状态。事件起始与结束帧、接触簇起始与结束帧必须作为重要参考帧保留，同时纳入动作切换、局部变化峰值、暴露较充分的清晰帧及均匀过程图像。候选筛选的数量、时间间隔和质量门槛随配置保存；不能因图像预算删掉唯一的前态或结果证据。

**每一张提交的候选帧**都附源帧号、采集时间戳、对应的动作／阶段、交互对象、动作证据来源与置信度、接触／物体状态、图像质量、遮挡和配准信息。图像提供完整画面及该帧当前目标范围的提示。模型看到的是这组带时序与动作信息的图像；任何仅在日志中出现而未实际提交的帧，都不能被模型引用为三帧结果。

### 4.3 Qwen3-VL-8B-Instruct 同时选择三帧

Qwen3-VL-8B-Instruct 结合候选图像、时间戳和逐帧动作信息，一次性选出：

1. **Pre**：尽量清楚显示关键操作前的物体、遮挡与搜索空间状态，且早于所选 PNR；不能仅因某帧是事件或接触簇首帧就选它。
2. **PNR**：显示目标动作展开、待查范围暴露或重要状态变化最充分且清晰的时刻。它不由首次接触、变化峰值、时间中点或固定帧号直接决定；动作之后可以复位。
3. **Post**：显示本次操作的结果或结束后的稳定状态，且晚于所选 PNR；不要求它必然是事件或接触簇的末帧。

模型同时判断该窗口是否为单次交互、是否疑似包含多次交互、前后状态是否完整、每个角色的证据是否足够。如果需要更多图像，可针对缺少的前态、关键过程或结果区间补充候选后再选；若仍无法可靠判断则输出 `uncertain`、缺失角色和原因，不为凑齐三帧编造画面。疑似多事件产生复核标记，不暗中改写上游事件边界。程序校验三个帧引用都属于实际展示集合、关联本事件或其明确登记的前后文，且满足 `t_Pre≤t_PNR≤t_Post`；三帧全部到达并完成解析后才能发布结果。每轮候选、提示词、原始响应、选择理由和模型耗时均保存。

**最终 Pre、PNR、Post 全部取自 Qwen3-VL-8B-Instruct 的选择结果。** 逐事件保存三个源帧号、时间戳、原图引用、候选依据、模型响应与质量状态。几何处理必须读取这三个最终帧；只有三个角色均已确认且引用有效时才进入三帧几何评分。待复核状态仍随结果保留，不能把“生成了三帧”解释为语义已获人工验证。

## 5. 将本次事件关联到搜索单元

对最终 Pre、PNR、Post 和完整事件过程，依据操作物体、动作、移开或打开后真正暴露的位置、候选目录版本，确定本次实际检查的稳定搜索单元集合 `I_t`。需要分清“接触杯子”“看见杯子”“检查杯子原占地”和“检查杯内”；只有被证据支持的空间范围才进入 `I_t`。多区域事件逐区域保存，不用单个事件分数覆盖所有区域。

每个关联条目记录 `episode_id`、`event_id`、`source_region_id`、`candidate_id`、稳定 `search_unit_id`、所属物体和大区、边界语义、对象证据与目录版本。若对象身份或相邻区域无法区分，保留待关联状态，不给错误区域写几何分数。固定承托面／原占地跟随空间范围，移动容器的内部跟随容器身份；同一对象的外部占地和内部是不同单元。

## 6. 用最终 Pre、PNR、Post 计算本次几何充分性

对每个 `u∈I_t`，按照 [几何定义](geometry_definition.md) 建立该单元的固定几何参考范围。当前明确描述的计算例子是**操作物体初始位置对应的局部外部支撑占地**；容器内部或整片候选区域只有在建立各自可解释的几何参考后，才可按相应范围评分。

1. 以最终 Pre、PNR、Post 的源帧号同步取左右目，校正双目并计算三帧深度和有效掩码。
2. 在操作初态确定物体掩码及邻近支撑面，将物体三维点投影到支撑面，得到非空固定参考点集 `R_t(u)`；在统计后续可见性前冻结它。若另用辅助帧建立参考，该帧不自动加入三帧可见证据。
3. 利用静态背景对应估计参考坐标到 Pre、PNR、Post 各相机坐标的变换，保存配准质量。
4. 对每个参考点逐帧检查：投影在图像内且位于相机前方，有有效深度，观测深度与预测深度差不超过 `ε=0.02 m`，并且没有被前景遮挡否决。
5. 同一点在三帧任意一帧通过检查就计一次，得到本次单元评分：

   `q_t(u)=|R_t(u)∩(V_{t,Pre}(u)∪V_{t,PNR}(u)∪V_{t,Post}(u))|/|R_t(u)|`。

这个分数是固定参考点中至少被一帧有效观察到的比例。PNR 帧露出、Post 帧重新遮挡的点仍计入本次检查；多帧重复观察不重复计数。已建立参考范围但某点深度或遮挡不确定时，该点留在分母且不进入分子。无法建立非空可信参考或完成配准时，整项结果记录为**不可计算**，不能把失败写为 `q=0`。逐区域保存参考点、三帧位姿、逐点可见状态、分数、质量诊断和失败原因。

## 7. 更新累积充分性并供下一次决策使用

确认事件结果可用后，按 `event_id` 和目录版本保存记忆 `before`。新发现且确认为独立待搜范围的单元以 `Q=0` 初始化；尚未确认的候选提议不作为已发现单元参与汇总。对每个稳定单元：

```text
未在本事件检查 u：          Q_t(u) = Q_(t-1)(u)
本事件有几何分数 q_t(u)： Q_t(u) = max(Q_(t-1)(u), q_t(u))
```

另存本次分数、最近一次检查结果、完整评分历史与事件引用，不把最近分数和累积状态覆盖成一个字段。若本次几何不可计算，保存 `q_t(u)=null` 和原因；已有数值 `Q` 保留，首次检查仍未知时保留未知状态。物理范围或被搜索内容改变时，先确定新单元或新参考版本及累积区间，不能把旧数值无条件解释为新状态的覆盖率。

物体层对它的**已发现单元**等权平均，大区层对它的**已发现物体／局部区域分组**等权平均：

`Q_t(o)=mean_{u∈U_t(o)}Q_t(u)`，`Q_t(m)=mean_{o∈O_t(m)}Q_t(o)`。

参与项存在未知时，主均值保持未知，并保存已知均值、未知数量及 `[0,1]` 假设下的上下界。发现新的待搜单元会扩大分母，因此物体或大区均值可能下降；既有单元的 `Q` 仍保留。跨事件 `max` 表示历史最佳单次评分，**不把两个互补视角的可见点合成覆盖并集**。

提交顺序为：校验事件身份及结果时间 → 锁定目录版本 → 保存 `before` → 区域关联及新单元发现 → 写逐区域几何 `q` → 更新单元 `Q` → 汇总物体与大区 → 保存 `after` 和更新依据 → 提交新记忆 → 下一次决策读取。重复提交同一事件应去重；若修订事件、三帧或几何参考，从最早受影响事件重放后续记忆，保留修订版本。

## 8. 一次事件的交付与复核

| 产物 | 最低要求 |
| --- | --- |
| 事件 | 源视频、事件 ID、起止源帧与时间、动作和边界证据、是否截断或待复核 |
| 最终三帧 | Qwen3-VL-8B-Instruct 选择的 Pre、PNR、Post 源帧号、时间戳与原图，候选集合、逐帧动作信息、模型请求和响应、选择理由及质量 |
| 区域关联 | 实际检查的每个 `search_unit_id`、边界语义、对象依据与目录版本 |
| 本次评分 | 每单元固定几何参考、三帧深度／位姿、逐点状态、`q`、质量和失败原因 |
| 累积状态 | 单元最近分数与 `Q`、物体和大区汇总、未知标记、`before`／`after` 快照与提交时间 |

程序可复算三帧时间顺序、候选引用、逐点三帧并集、单元 `max` 更新及分层均值。独立视觉复核还需检查事件边界、接触对象、Pre／PNR／Post 角色、实际检查区域和几何参考范围是否正确；结构检查通过本身不能替代这些准确性证据。

## 9. 仓库中的对应实现

`event_frontend` 提供 100DOH 检测、TSM 动作、视觉信号、cycles 事件边界，以及逐事件对象／接触簇和候选排序的代码。`spatial_memory.candidates` 从事件区间导出带时间戳和动作信息的候选帧，并保留起止参考帧。`spatial_memory.selection` 调用 Qwen3-VL-8B-Instruct，同一请求选择全部三帧并给出候选区域关联。`spatial_memory.geometry` 对固定局部支撑占地建立参考并求三帧可见并集；`spatial_memory.memory` 按时间顺序更新 Q 和层级均值。

`spatial_memory.geometry_compiler` 已接入自动流程：最终源帧同步双目 → Fast-FoundationStereo 深度 → 8B 物体定位与 FastSAM 掩码 → 标定后的源帧手部排除 → 初态固定支撑占地 → 静态配准及质量检查 → 三帧可见并集和记忆重放。模型权重、原始视频和源帧手部检测由运行环境提供；深度和掩码在最终选定帧上重新生成。标定 IMU 初态方向约束水平承托面，单次局部点未知留在固定分母。

当前实测模型已按用户确认更正为 Qwen3-VL-8B-Instruct，真实三段结果见 [8B 验证](QWEN8B_VALIDATION.md)。局部占地以独立搜索单元记录，不传播为整个文字候选的覆盖；多区域关联到同一几何范围时去重并保留歧义。容器内部等缺乏相应固定参考几何的区域保持不可计算。完整验证保留输入哈希、实际模型标识、三帧版本、几何配置和记忆版本。
